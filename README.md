# 📚 わたしの本棚 - 読書管理アプリ

シンプルで使いやすい読書管理Webアプリケーションです。読んだ本の記録、評価、書評を本棚風のUIで管理できます。

## ✨ 機能

- **本の登録・編集・削除**
  - タイトル、開始日、終了日、5段階評価、書評、表紙画像
  - 状態管理（未読、読書中、読了）

- **本棚風UI**
  - 表紙画像をカード形式で表示
  - 本を押すと詳細ページへ遷移

- **ソート機能**
  - 開始日（昇順・降順）
  - 終了日（昇順・降順）
  - 評価（昇順・降順）

- **フィルタリング**
  - 状態（未読、読書中、読了）
  - 期間指定
  - 複数条件の組み合わせ

- **PWA対応**
  - オフラインでも動作
  - ホーム画面に追加可能
  - アプリのようなUX

## 🚀 セットアップ

### 必要な環境

- PHPが動作するWebサーバー（さくらレンタルサーバー推奨）
- PHP 7.4以上
- MySQLデータベース（5.7以上推奨）

### インストール手順

1. **ファイルのアップロード**
   ```bash
   # すべてのファイルをサーバーにアップロード
   # FTPクライアント（FileZilla等）を使用
   ```

2. **パーミッション設定**
   ```bash
   # アップロードディレクトリに書き込み権限を付与
   chmod 777 uploads
   ```

3. **データベース設定**
   ```bash
   # MySQLデータベースを作成
   mysql -u root -p
   CREATE DATABASE mybook CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

   ```bash
   # api/config.php に接続情報を設定
   # api/config.sample.php をコピーして作成してください
   cp api/config.sample.php api/config.php
   # config.php を編集してMySQL接続情報を設定
   ```

4. **テーブル初期化**
   - 初回アクセス時に自動的にテーブルが作成されます

5. **ブラウザでアクセス**
   ```
   https://your-domain.com/mybook/
   ```

```
├── sw.js              # Service Worker

│   └── style.css      # スタイルシート
├── js/
│   └── app.js         # JavaScript
├── api/
│   ├── config.php         # データベース接続設定
│   ├── config.sample.php  # 設定ファイルサンプル
│   ├── db.php             # データベース接続

│   └── upload.php         # 画像アップロード
└── uploads/               # 表紙画像保存先
```

## 💡 使い方

### 本の登録

1. トップページの「+ 新しい本を登録」ボタンをクリック
2. タイトル、状態、日付、評価、表紙画像、書評を入力
3. 「登録」ボタンをクリック

### 本の閲覧

- トップページに本棚風に表示される本をクリックすると詳細ページへ

### 本の編集・削除

- 詳細ページで「✏️ 編集」または「🗑️ 削除」ボタンをクリック

### フィルタリング・ソート

- トップページのコントロールパネルから設定
- 複数条件の組み合わせも可能

### PWAとしてインストール

1. ブラウザのメニューから「ホーム画面に追加」を選択
2. アプリとしてインストールされ、オフラインでも動作

## 🐛 トラブルシューティング

### 画像がアップロードできない

- `uploads/`ディレクトリのパーミッションを確認（777）
- `.htaccess`のアップロードサイズ制限を確認

### データベースエラー

- `api/config.php`の接続情報を確認
- MySQLサーバーが起動しているか確認
- データベース`mybook`が作成されているか確認
- ユーザーに適切な権限が付与されているか確認

### PWAが動作しない

- HTTPSでアクセスしているか確認（ローカル環境ではhttp://localhostも可）
- ブラウザがService Workerをサポートしているか確認
