# 📚 わたしの本棚 - 読書管理アプリ

シンプルで使いやすい読書管理Webアプリケーションです。読んだ本の記録、評価、書評を本棚風のUIで管理できます。

## ✨ 機能

- **本の登録・編集・削除**
  - タイトル、開始日、終了日、5段階評価、書評、表紙画像
  - 状態管理（未読、読書中、読了）

- **本棚風UI**
  - 表紙画像をカード形式で表示
  - 本を押すと詳細ページへ遷移

- **ソート機能**
  - 開始日（昇順・降順）
  - 終了日（昇順・降順）
  - 評価（昇順・降順）

- **フィルタリング**
  - 状態（未読、読書中、読了）
  - 期間指定
  - 複数条件の組み合わせ

- **PWA対応**
  - オフラインでも動作
  - ホーム画面に追加可能
  - アプリのようなUX

## 🚀 セットアップ

### 必要な環境

- PHPが動作するWebサーバー（さくらレンタルサーバー推奨）
- PHP 7.4以上
- SQLite3サポート

### インストール手順

1. **ファイルのアップロード**
   ```bash
   # すべてのファイルをサーバーにアップロード
   # FTPクライアント（FileZilla等）を使用
   ```

2. **パーミッション設定**
   ```bash
   # アップロード、データディレクトリに書き込み権限を付与
   chmod 777 uploads
   chmod 777 data
   ```

3. **データベース初期化**
   - 初回アクセス時に自動的にSQLiteデータベース（`data/books.db`）が作成されます

4. **ブラウザでアクセス**
   ```
   https://your-domain.com/mybook/
   ```

## 📁 ディレクトリ構成

```
mybook/
├── index.html          # メインページ（一覧表示）
├── detail.html         # 詳細ページ
├── register.html       # 登録・編集ページ
├── manifest.json       # PWA manifest
├── sw.js              # Service Worker
├── .htaccess          # Apache設定
├── README.md          # このファイル
├── css/
│   └── style.css      # スタイルシート
├── js/
│   └── app.js         # JavaScript
├── api/
│   ├── db.php         # データベース接続
│   ├── books.php      # 書籍CRUD API
│   └── upload.php     # 画像アップロード
├── uploads/           # 表紙画像保存先
└── data/
    └── books.db       # SQLiteデータベース（自動生成）
```

## 💡 使い方

### 本の登録

1. トップページの「+ 新しい本を登録」ボタンをクリック
2. タイトル、状態、日付、評価、表紙画像、書評を入力
3. 「登録」ボタンをクリック

### 本の閲覧

- トップページに本棚風に表示される本をクリックすると詳細ページへ

### 本の編集・削除

- 詳細ページで「✏️ 編集」または「🗑️ 削除」ボタンをクリック

### フィルタリング・ソート

- トップページのコントロールパネルから設定
- 複数条件の組み合わせも可能

### PWAとしてインストール

1. ブラウザのメニューから「ホーム画面に追加」を選択
2. アプリとしてインストールされ、オフラインでも動作

## 🐛 トラブルシューティング

### 画像がアップロードできない

- `uploads/`ディレクトリのパーミッションを確認（777）
- `.htaccess`のアップロードサイズ制限を確認

### データベースエラー

- `data/`ディレクトリのパーミッションを確認（777）
- PHPのSQLite3サポートを確認

### PWAが動作しない

- HTTPSでアクセスしているか確認（ローカル環境ではhttp://localhostも可）
- ブラウザがService Workerをサポートしているか確認
